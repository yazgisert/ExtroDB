Proteome Index Predictor Models

Extremophile predictors trained on protein language model embeddings of the curated proteomes. Download the input sequences and biotrainer files of every model and compare their performance on held-out prokaryotes and on eukaryotic algae.

Models & data

How to use the files

Every model was trained and evaluated with all four embedders. For each model you can download the input FASTAs per split (header with the label: >protein_id label=halophile proteome=GCF_…) and a zip for retraining with biotrainer. The zip holds the input FASTA in biotrainer format, one config per embedder and the output of our run (test metrics, training log, model checkpoint). Embeddings are not included; biotrainer computes them from the config. Extremophile proteins are MMseqs2 cluster representatives; non-extremophiles are clustered at 30% identity as well, so no test protein has a close relative in training. Error bars show 95% bootstrap confidence intervals; hover over a bar for the exact values.

6-class model

Five extremophile classes plus non-extremophile in one model (ProtT5 only). Its test set is the binary test set.

Test set

Eukaryotic algae

Proteomes of extremophilic algae, used only for testing the binary models. Proteins with at least 30% identity to a prokaryote training or validation protein were removed.
